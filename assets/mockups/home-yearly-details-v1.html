ปัญหาของแบบเดิม

  1. เทียบไม่แฟร์ — เอา 24 วันของเดือนนี้ไปเทียบกับ “ทั้งเดือน” ก่อน เลยออกมา -88%, -114% ดูน่ากลัวเกินจริง
  2. เปอร์เซ็นต์อ่านยาก — “-114.5%” หรือ “-86.7pp” คนทั่วไปไม่รู้แปลว่าดีหรือแย่ และลูกศรลงสีเขียว/แดงปนกันทำให้งง
  3. คำว่า “จากเดือนก่อน” ลอยอยู่บรรทัดสุดท้ายแบบไม่มีตัวเลข
  4. “อื่นๆ” ซ้ำ 2 แถว (อันหนึ่งคือรายการที่ยังไม่มีหมวด) และสีแท่งไม่ได้สื่อความหมาย
  5. มีแต่ตัวเลข ไม่บอกว่าต้องทำอะไรต่อ

สิ่งที่แบบใหม่เปลี่ยน

  1. สรุปเดือนนี้ในประโยคเดียว + แถบรับ/จ่ายแบบเดียวกับรายปี ให้รู้ภาพทันที
  2. บอกวันที่ / วันที่เหลือ ให้รู้ว่าเดือนยังไม่จบ
  3. เทียบช่วงวันเดียวกัน (1–24 ก.ย.) และบอกเป็น บาท แทน % — สี: เขียว = ดีต่อเรา, แดง = ควรระวัง
  4. ตัดแถว “อัตราการออม” ออกจากส่วนนี้ (รายได้เดือนนี้ยังเข้าไม่ครบ ตัวเลขติดลบจะทำให้ตกใจโดยไม่จำเป็น)
  5. หมวดหมู่เป็นลิสต์เรียงลำดับ มีไอคอน + % ของรายจ่ายทั้งหมด, แท่งสีเดียว, รวม “อื่นๆ” เป็นแถวเดียว
  6. ชวนจัดหมวดรายการที่ยังไม่มีหมวด และปุ่ม ดูรายการทั้งหมด ไปหน้าการเงิน
  7. โทนข้อความแบบโค้ช — ไม่ตำหนิ (ตาม UX_GUIDELINES)
