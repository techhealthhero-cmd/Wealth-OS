3 ทางเลือกใหม่ (ใช้แทนแท็บ “เดือนนี้” ของ v1 ได้)

  1. C · จังหวะการใช้เงิน — กราฟเส้นสะสมเทียบเดือนก่อน ณ วันเดียวกัน ตอบคำถาม “เดือนนี้ใช้เร็วไปไหม?” ได้ทันที + ปฏิทินสีเข้ม/อ่อนตามยอดใช้รายวัน เห็นว่าวันไหนใช้หนัก
  2. D · หมวดหมู่เทียบเดือนก่อน — แถบสัดส่วนเส้นเดียว + ทุกหมวดมีป้าย ↑/↓ เป็นบาท บอกทันทีว่าหมวดไหนเพิ่ม (ชมพู) หมวดไหนลด (เขียว) แล้วพาไปตั้งงบ
  3. E · สรุปเป็นข้อ — เน้นการกระทำ: วงแหวน “ใช้ไปกี่ % ของรายรับ” + 3 การ์ดข้อสังเกต แต่ละข้อมีปุ่มทำต่อ ตัวเลขดิบพับไว้ใน “ดูตัวเลขทั้งหมด”

เทียบกัน

  • C เหมาะกับคนที่อยากคุมจังหวะรายวัน — ต้องบันทึกสม่ำเสมอถึงจะสวย
  • D เหมาะกับคนที่อยากรู้ว่าเงินรั่วตรงไหน — ใกล้ของเดิมที่สุด ทำง่ายสุด
  • E ตรงกับแนว “Next Best Action” ของ WEALTH OS มากที่สุด — อ่านน้อย ทำต่อได้ทันที
  • ผสมได้ เช่น การ์ดข้อสังเกตของ E ไว้บน + รายการหมวดของ D ไว้ล่าง
